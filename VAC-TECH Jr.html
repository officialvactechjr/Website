What the club does

Workshops

Hands-on sessions run by senior members and invited teachers. You write code during the session and leave with something working.

Projects

Members build their own apps, sites and tools. Approved work goes on the projects page with the builder's name and GitHub link.

Events

Quizzes, coding contests and talks across the year. Registration opens on the event page for a set time, then closes.
